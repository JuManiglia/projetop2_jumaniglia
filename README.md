# Projeto de Desenvolvimento Mobile — FATEC

## Sobre o projeto

Aplicativo desenvolvido originalmente em 2024 como
atividade acadêmica da disciplina de Desenvolvimento
Mobile do curso de Análise e Desenvolvimento de Sistemas
da FATEC.

O projeto teve como objetivo aplicar os conhecimentos
adquiridos durante a disciplina, por meio do
desenvolvimento de uma aplicação utilizando Flutter,
Dart e Firebase.
